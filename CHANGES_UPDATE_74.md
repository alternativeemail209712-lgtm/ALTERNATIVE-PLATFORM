# UPDATE 74 — Legend customization: remove ANY entry

* Every legend entry (the game's built-in ones AND custom ones) now has a ✕ delete button in Settings -> Color legend.
* Deleted built-in entries are remembered (`removed` list) so they do not come back on reload or on other screens.
* New "Restore removed entries" button brings all deleted built-in entries back; "Reset legend to default" still resets everything.
* Works for every game that uses the shared legend (legend.js + legend-hub.js).
