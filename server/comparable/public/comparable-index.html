Color shades

Choose how strong each color (green and grey clues, blue consonant tiles and orange vowel tiles) looks, in the tiles, the symbol row, the legend and the keyboard. Ten shades per color, from lightest to darkest (the middle one is the standard look). It applies right away - no new round needed - and every screen connected to this game changes together.

Win celebration

After a win, the leaderboard pops up automatically, then closes on its own. Auto-continue (above) always waits for this celebration to finish before starting the next round.

Starter word

On (default): one random word that fits the symbol row is placed on the board for free at the start of each round (worth no points) so chat has first colors to read (when no other word fits the symbol row, the round simply starts blank). Off: every round starts on a blank board. Takes effect from the next round; your choice is remembered.

Strict fit

On (default): a guess must still fit the colors of every guess on the board, otherwise it is skipped with the message below. Off: any real word that matches the symbol row is accepted and colored, so chat can probe freely. (A guess must ALWAYS match the symbol row.) Your choice is remembered and applies right away.

Auto-color keyboard keys

On (default): every key on the keyboard takes the same color as its letter's tiles on the board - the best clue wins (green, then grey). Off: the keys stay plain (neutral) - viewers only read the colors on the tiles. Applies right away on every connected screen and is remembered.

Guess rejection message

Shown briefly whenever Strict fit skips a guess.

    How to play

    • Guess the hidden word — any length you like, chosen in Settings. Unlimited guesses, anyone can play, anytime.
    • Above the board is a row of round tiles, one per letter: B Blue = a consonant, O Orange = a vowel.
    • Between two neighbouring tiles a sign compares the two letters (A is the smallest letter, Z the largest):
      < the right letter is larger · > the right letter is smaller · = both letters are equal.
    • Inside every blue tile an arrow compares that consonant with the next consonant of the word (vowels are skipped):
      ▲ the next consonant is larger · ▼ the next consonant is smaller · — the next consonant is the same. The last consonant has no arrow.
    • Every guess must be a real word that matches this symbol row. Example: c a n a l = c > a < n > a < l with c ▲ … n ▼ … l.
    • After every guess each letter turns Green or Grey:
      Green — the letter is correct and in the right position.
      Grey — the letter is incorrect.
    • The keyboard colors itself to match the tiles — green or grey — so there is nothing to mark by hand. Everything resets each new round.
    • A word already on the board is skipped. Strict fit is on by default, so only guesses that still fit every earlier color are accepted; the host can switch it off in Settings.
    • Scoring (Live): 1 point for every guess that fits the board, 5 points for solving the round.
    • 💡 unlimited hints suggest a word that fits the symbol row and the clues so far (never the answer). Difficulty (Normal/Medium/Hard/Random) sets how tricky the word itself is.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
