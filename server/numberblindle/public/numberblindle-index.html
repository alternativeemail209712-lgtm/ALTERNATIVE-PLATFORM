Number length

digits

Each new round picks a random number of digits in this range (default 5 to 8).

Secret number

On (default): digits can appear more than once, like the original Tebak Pin (e.g. 5 9 5 7 9 4 1). Off: every digit of the secret number is different (numbers longer than 10 digits always repeat). Takes effect from the next round, after you tap Apply.

Number keyboard

One row of ten keys. Every key takes the color of its digit on the tiles (green, yellow or red) - mark a digit on a tile or on its key and both change together. You can also show / hide it with the ⌨️ button in the top bar. Saved on this device.

Color shades

Choose how strong the green, yellow and red of the tiles, keys, count columns and legend look. Ten shades per color, from lightest to darkest (the middle one is the standard look). It applies right away - no new round needed - and every screen connected to this game changes together.

Win celebration

After a win, the leaderboard pops up automatically, then closes on its own. Auto-continue (above) always waits for this celebration to finish before starting the next round.

Starter number

On (default): one random number is placed on the board for free at the start of each round (worth no points) so chat has green / yellow / red counts to read. Off: every round starts on a blank board. Takes effect from the next round; your choice is remembered.

Strict fit

On (default): a guess must still fit the green / yellow / red counts of every guess on the board - one that contradicts an earlier clue is skipped with the message below. Off: any number with the right count of digits is accepted and counted, so chat can probe freely. Your choice is remembered and applies right away.

Guess rejection message

Shown briefly whenever Strict fit skips a guess that conflicts with an earlier clue.

Number length, repeated digits, auto-continue and this delay only take effect once you tap Apply. Win-celebration duration applies right away.

    How to play

    • Guess the secret number (a PIN of 5 to 8 digits by default, set in Settings). Type just the digits in chat. Unlimited guesses, anyone can play, anytime. Digits can repeat.
    • Each guess shows number columns to its right. They only reveal counts, never which digits:
      Green = digits that are correct and in the right position.
      Yellow = digits that are in the secret number but in the wrong position.
      Red = digits that are not in the secret number.
    • Use the counts to work out the digits, then color them on the tiles: tap a digit to cycle red → yellow → green → none. The number keyboard (0 - 9) colors itself to match every tile, and the tiles match the keys. The only automatic color: a guess with 0 green and 0 yellow turns all its digits red. Everything clears at the start of each new round.
    • With Strict fit on (the default), a guess is only accepted if it still fits every clue so far; one that contradicts an earlier clue flashes a quick reason and is skipped.
    • Scoring (Live): 1 point for every guess that fits the board, 5 points for the guess that solves the round.
    • 💡 unlimited hints: a number that fits the clues (never the answer), a revealed digit, or digits that are not in the number.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
