Starter word

Off (default - the grid is already the first clue): every round starts on a blank guess board. On: one random word made of grid letters is placed on the board for free at the start of each round (worth no points) so chat has first colors to read. Strict fit

Off (default): any real word made only of letters that are on the grid is accepted and colored, so chat can probe freely. On: a guess must also still fit the colors of every guess on the board, otherwise it is skipped with the message below. (A guess must ALWAYS be a real word of the right length that only uses grid letters.) Your choice is remembered and applies right away.

    How to play

    • Guess the hidden word — its length is chosen in Settings (4 to 20 letters). Unlimited guesses, anyone can play, anytime.
    • The board is a grid of tiles: 5 × 5 for 4–5 letter words, 8 × 8 for 6–9 letters and 10 × 10 for 10–20 letters. Every tile shows a letter and a number.
    • The number tells how many of the touching tiles — diagonals included — hold a letter that is used in the secret word.
    • The host taps a tile to mark its letter: 1× Blue = the letter is in the word, 2× Red = not in the word, 3× = clear the mark. Every tile with the same letter changes together.
    • Blue letters are collected in the Letter bank (the host can hide it in Settings). Reset marks clears all marks (the host can hide that button in Settings). When the round is solved, every tile turns blue or red by itself to show which letters are in the word.
    • Chat guesses real words of the right length, made only of letters that are on the grid (letters can be reused freely).
    • After every guess each letter turns Green, Yellow or Grey:
      Green — correct letter, right position.
      Yellow — the letter is in the word but in the wrong position.
      Grey — the letter is not in the word.
    • A word already on the board is skipped. Strict fit is off by default; the host can switch it on in Settings so only guesses that still fit every earlier color are accepted.
    • Scoring (Live): 1 point for the guess that solves the round.
    • 💡 unlimited hints suggest a word made of grid letters that fits the clues so far (never the answer). Difficulty (Normal/Medium/Hard/Random) sets how tricky the word itself is.
    • Live = real TikTok chat. Test = simulated chat, nothing saved. Offline = just you, type guesses directly.
